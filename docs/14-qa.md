# Q&A (17:40–18:00)

[← Agent as explorer](13-agent-as-explorer.md) · [Agenda](00-agenda.md)

Twenty minutes for your questions: about Geant4, the agent, Ares and PLGrid, or using any of this on your own problem. No question is too basic.

## Bring one story

The most useful thing you can share is a moment from your mission:

- **The agent got something wrong, and here's how I caught it.** Which stage? What gave it away: a number, the geometry viewer, an overlap check, a hand estimate?
- **Human approval paid off.** A stage where reading before pressing Enter changed the result.
- **It surprised me.** A result, or something the agent did on its own, that you didn't expect.

## Questions to get us started

If the room is quiet, we'll pick from these:

1. Which mistake would you **not** have caught without a reference value to compare with?
2. When was the guided prompt better than the full one, and when worse?
3. What did the agent do well that would have taken you much longer by hand?
4. Would you trust a result from this pipeline in a paper? What would you check first?
5. How would you set this up for your own simulation: what goes in the prompt, what do you check?
6. What changes when the model is a frontier model instead of an open-weight one, and what doesn't?

## Take-home checklist

Whatever agent and model you use next, these habits carried the afternoon:

- [ ] **Predict first.** Write down what you expect before you run anything.
- [ ] **Pin down what matters** in the prompt (geometry, units, beam, scoring, statistics); let the agent propose the rest, then review it.
- [ ] **Look at the geometry**, not only the code: viewer, overlap check, a geantino or a table of positions.
- [ ] **Read before approving.** Every stage, every command that changes something.
- [ ] **Check against something independent:** a table, a hand estimate, energy conservation.
- [ ] **Ask for uncertainties**, and for the run time before anything long starts.
- [ ] **Ask where each number comes from**, and open the source yourself for the ones that matter.
- [ ] **Keep it reproducible:** each run's `run.sh` reruns it without the agent.
